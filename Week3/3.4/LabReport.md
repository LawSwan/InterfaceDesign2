# React State and Hooks Lab Report

## Project Summary
This assessment required implementing React functional components using state and hooks for the following tasks:
- Simple counter with increment/decrement and minimum zero guard
- Text input field showing live text output
- Todo list with add and remove functionality

## Code Files
- Main application: src/App.jsx
- Styling: src/App.css and src/index.css
